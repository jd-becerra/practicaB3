## Objetivo

El objetivo de esta práctica es realizar un concepto para la <i>landing page</i> de un sitio responsivo.
El sitio en específico es marca.com, un sitio de noticias deportivas.

## Las tecnologías utilizadas fueron:
* **Figma** para desarrollar un prototipo no funcional antes de desarrollar.
* **React.js** como framework Front-end para facilitar el desarrollo del proyecto.
* **TailwindCSS** para simplificar el maquetado de la página y obtener una página responsiva que funcionara en diferentes plataformas (web, móvil, etc.)
